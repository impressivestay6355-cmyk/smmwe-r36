# Getting the SMM:WE APK

SMM: World Engine is a free fan game. Download the **Android** version from
the official SMM:WE channels (website / Discord of the SMM:WE team).

This project does not host or link to APK files.

- Use the **arm64** Android APK (it contains `lib/arm64-v8a/`).
- Both versions work: **Fullscreen** and **Keep Aspect Ratio**.
- Tested with version 3.5.1.

Put the APK in `ports/smmwe/Setup/` and start the port.
