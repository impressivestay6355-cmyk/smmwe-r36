# SMM: World Engine

Port by Impressive Stay. SMM:WE created by Franyer Farías, developed by the SMM:WE team.

The game is not included.

## Install

1. Copy `smmwe/` and `SMM World Engine.sh` into `ports/`.
2. Put the SMM:WE Android APK (arm64, Fullscreen or Keep Aspect Ratio) in
   `smmwe/Setup/`.
3. Start the port. The first launch takes about a minute.

To update or switch version, put the new APK in `Setup/` again.

## Account

SMM:WE is an online game: you need an SMM:WE account and an internet
connection (Wi-Fi) to log in and play.
How to create an account: https://youtu.be/Cmlpp2RoutE

## Controls

| Button | Action |
| --- | --- |
| START | pause / confirm |
| Right stick | pointer |
| R3 | click |
| L2 | pointer on / off |
| SELECT + START | quit |

The on-screen keyboard opens by itself when the game asks for text.

## Levels and mods

- Levels (`.swe`, `.zip`): `Import Levels/`, then the in-game import button.
- Textures (`.zip`): `Import Levels/Mods and Textures/`, then Settings → import textures.
- Music and sounds (`.ogg` or a `.zip` of them): `Import Levels/Mods and Textures/`,
  applied at the next start.

Saves are in `saves/`, the log in `log.txt`.
